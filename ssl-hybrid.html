Explainers / SSL Hybrid

SSL Hybrid, explained from the source

SSL Hybrid by Mihkel00 is the most-boosted SSL script on TradingView. It was built for the NNFX way of trading, and its own header says it is meant for daily charts. It stacks four lines on the price chart, colours the bars, draws arrows and diamonds, and adds a small "Risk" table. People mostly ask for its best settings. The code shows something more useful first: what each line actually is, and that two of the settings people tune do not touch the line they think they do.

The one rule behind every SSL line

An SSL line is two moving averages, one of the highs and one of the lows. The rule is the same for every SSL line in this script:

  • if the bar closes above the average of the highs, the state is up;
  • if it closes below the average of the lows, the state is down;
  • if it closes in between, the state stays what it was.

In an up state the line is drawn on the average of the lows; in a down state, on the average of the highs. That is why it jumps from one side of price to the other when the state flips.

The four lines

LineWhat it is (defaults)Its settings
Baselinea moving average of close, HMA 60, with a thin channel of 0.2 x the 60-bar average true range either sideBaseline Type, Baseline Length, Channel Multiplier
SSL1the SSL rule on an HMA 60 of highs and lowsnone of its own: it always uses the Baseline Type and Length
SSL2 (dots)the SSL rule on a fast "JMA" 5 of highs and lowsSSL2 Type, SSL2 Length, Continuation ATR Criteria
Exit (arrows)the SSL rule on an HMA 15 of highs and lowsExit Type, Exit Length

So if you change "SSL2 Type" hoping to change the thick SSL1 line, nothing happens to it. To change SSL1 you have to change the Baseline as well.

The bars are coloured by the Baseline channel: above the channel, the bullish colour; below it, the bearish colour; inside it, grey. The "JMA" option is a public approximation of a Jurik-style smoother, not Jurik Research's own JMA.

The arrows, the dots and the diamond

  • Arrows mark the close crossing the Exit line. The alerts name a cross down "EXIT LONG" and a cross up "EXIT SHORT".
  • SSL2 dots take the bullish colour when the close is above both the Baseline and SSL2 and SSL2 is within 0.9 ATR of the close (the bearish colour for the mirror case). The script calls this "continuation".
  • The white diamond appears when a candle's body is bigger than one ATR while the Baseline is within one ATR of the close. The script calls it a possible false breakout. It is a test of candle size only; nothing in the code checks what happened after.

What the Risk table measures

  • Risk Level is how today's ATR ranks against the last 100 bars: above the 75th percentile it says "High", below the 25th "Low". It is a volatility rank, not a measure of how likely a trade is to lose.
  • Entry Distance is how far the close is from the Baseline, in ATRs: under 1 "Near", under 2 "Extended", otherwise "Far".
  • Vol %ile and ATR show the two raw numbers.

The table sits in the bottom-right corner, where TradingView's own badge can cover part of it.

Does SSL Hybrid repaint?

Closed bars do not change. The script makes no higher-timeframe requests, so history stays put.

The live bar does. Every state, bar colour, dot colour, arrow and alert is worked out from the current price, so they can appear and disappear while the bar is still forming. On random-walk prices (our simulation, 230,000 bars, SSL Hybrid's default rules re-implemented and replayed tick by tick inside each bar), an exit arrow showed up during the bar and was gone at the close on about 11% of bars, against about 15% of bars that kept one. Roughly four in ten arrows you might see live would not survive the close. Set alerts to fire once per bar close if you want only the ones that stay. More in what repainting is.

How often it changes its mind

In the same simulation, at the default settings:

Eventhow often
Exit arrow (close crosses the Exit line)one every 7 bars
Next exit arrow within 5 barsafter 43% of arrows
SSL1 changes stateevery 15 bars
Bar coloured grey (inside the Baseline channel)8-9% of bars
White diamond6% of bars

Random-walk prices have nothing to predict, so these numbers describe how the rules react to noise, not how they trade. They are a floor for how busy the chart will look.

Where it fails

  • The live bar is provisional. Arrows, colours and alerts can appear and vanish until the close.
  • The Exit line flips often. At the default, the next arrow came within five bars after more than four in ten arrows on noise.
  • SSL1 is tied to the Baseline. Tuning the SSL2 or Exit settings never changes it.
  • "Risk" is a volatility rank. High ATR is labelled high risk; it says nothing about the odds of a trade.
  • The diamond is a candle-size test. The code never checks whether a flagged candle was a false breakout.
  • No test of any setting. There is no record in the script of how any combination performed, and "best settings" copied from a daily forex chart are a different tool on a 5-minute crypto chart.
