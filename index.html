What it actually computes

Wilder's Relative Strength Index, in full:
RS  = (smoothed average gain over N) / (smoothed average loss over N)
RSI = 100 - 100 / (1 + RS)
Two details matter more than the formula itself.

The "average" is not an average. Wilder used his own smoothing - an exponential filter with alpha = 1/N, not a simple mean of the last N bars.

The inputs are close-to-close changes. Nothing else enters. Not the high, not the low, not the volume, not the order of events inside the bar.

So RSI is a smoothed ratio of recent up-closes to recent down-closes, squashed onto a 0-100 scale. That is the entire content. Everything an RSI can tell you is already in the sequence of closes; the indicator is a compression of that sequence, not an addition to it.

"Overbought" means the security has been going up

Strip the vocabulary away. A high RSI is a statement that recent closes have risen more than they have fallen, smoothed. That is it. There is no mechanism inside the formula that makes a high reading imply a coming reversal, and nothing in the arithmetic that knows what "too far" means.

If someone tells you RSI over 70 means a security is due to fall, ask what in the formula produces the word "due". There isn't anything. The claim may still be true for some instrument in some regime - but it is not a property of the indicator, and it has to be demonstrated separately every time.

02 / TradingView scripts

Honest tools, and where they fail.

Each tool is designed to make a familiar chart question easier to inspect—not to decide for you.

Free / live now

ATR Trailing Stop with Flip Audit

Trend overlay

An ATR trailing stop that draws its stop line, confirms flips only at the bar close, and counts how many flips were undone within a few bars, so the cost of a tight setting is visible on your own chart. It rebuilds the stop rule behind UT Bot Alerts from scratch, with credit to the original authors. Where it fails: Every flip is late by about the stop distance, and it has no neutral state: it is always on one side, trending or not.

Open script

Sample Size Panel

Statistics panel

Enter how many trades you have and the rate that worked, and the panel shows the range the true rate plausibly sits in (a Wilson interval), whether that range can be told apart from 50 percent at all, and roughly how many trades it would take to narrow it, next to how many this chart's history could even give. Where it fails: It assumes every trade is an independent draw from one unchanging rate; real trades cluster and regimes change, so the true uncertainty is wider than the panel shows.

Open script

Support & Resistance Touch Count

Levels overlay

Draws support and resistance zones from recent swing pivots and counts how often price actually returns to them, then compares that rate with a control set of plain round-number levels on the same chart, so you can see whether the zones earn their place. Where it fails: An entry is not a reaction: the count says price came back to a zone, not that it turned there, and one chart is one sample.

Open script

Swing Ratio Grid

Levels overlay

A retracement grid that shows the two things most Fibonacci rules leave out: which swing was measured and which ratio set was used. Includes an arbitrary 0.4 / 0.5 / 0.6 control grid so you can see how little the exact ratios matter. Where it fails: The swing depends entirely on the lookback, and a new pivot redraws every level.
