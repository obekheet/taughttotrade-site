What a report looks like

This is a shortened excerpt from an audit we ran on our own open-source script, Range Filter Audit. It is our code, not a customer's, and nobody paid for it. The flaw is ours, and the published script still has it.

Medium: alerts can fire on a turn that does not survive the bar (lines 94-95)

alertcondition(turnUp, "Range filter turned up", "Range Filter Audit: filter turned up on {{ticker}} {{interval}}")
alertcondition(turnDn, "Range filter turned down", "Range Filter Audit: filter turned down on {{ticker}} {{interval}}")

What happens. turnUp and turnDn are recalculated on every live update. The markers on lines 89-92 split this into closed-bar triangles and open-bar circles. The alerts do not. With the alert frequency set to "Once per bar", an alert can fire on an open-bar turn and the bar can then close with no turn. Our published description tells users to pick "Once per bar close", but nothing in the code enforces it.

How to see it on a chart. Add the script to a 1-minute chart while the market is open and create an alert with "Once per bar". Wait for a grey circle that disappears before the bar closes. You should then see an entry in the alert log and no triangle on that bar.

Suggested change. Add and barstate.isconfirmed to both conditions, or offer a separate open-bar alert with a title that says so.

This finding comes from reading the code. We did not test it on a chart. Other findings were tested on a Python port with synthetic data.

Where this fails

  • It finds problems in the code it can read. It cannot prove a script is safe, and a clean section does not mean nothing is wrong.
  • If the audit finds nothing, the report says so and lists what was checked. That is not proof either.
  • It covers the code at the link you send. A later edit is not covered.
  • It cannot see closed-source libraries, your chart settings, your data feed or your broker.
  • AI reading can miss things or misjudge them. You can check any finding against your code by its line numbers, and most also say how to see it on a chart. No report can show you what it missed.
  • Fixed code changes the problems named in the report and nothing else. It has not been run live, it can still have problems the report missed, and we have no sample of this option yet.
  • It does not test whether a script makes money, and it gives no trade advice.
  • A report is only useful if you can act on it. If you cannot edit Pine yourself and do not want the $149 option, the $49 report will tell you what is wrong and leave it that way.
